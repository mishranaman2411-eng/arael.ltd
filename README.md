# ARAEL — Wear Your Vibe, Honor Your Roots

Editorial Streetwear Lookbook & High-Fashion Storefront for **ARAEL** Drop 01.

## Features
- **Heritage Meets Streetwear Aesthetic:** Authentic Indigo & Raw Khadi palette (`--khadi: #F4F1DE`, `--ink: #0D1B2A`, `--navy: #1B263B`, `--slate: #415A77`, `--sage: #778D7A`, `--sandstone: #D4C4A8`).
- **Sequenced Entrance Animation:** GSAP-orchestrated hero typography entrance followed by elastic back-out spring-in of signature lookbook garments.
- **Streetwear Lookbook Cards:** Clean sharp-edged slide-up bottom hover bar displaying garment title, INR price, and minimal `VIEW +` action with subtle image zoom.
- **Editorial Slide-Over Drawer:** Full-height slide-over product inspection drawer with sharp 0px corners, edge-to-edge product photography, dynamic hover zoom, stacked typography, rectangular 5-column size grid (`XS`, `S`, `M`, `L`, `XL`), bold full-width `ADD TO BAG` CTA, underlined `BUY NOW` checkout link, and collapsible specification accordions (`DETAILS +`, `SIZE & FIT +`, `SHIPPING & CARE +`).
- **Interactive Top-Selling Carousel & Configurator:** Tactile 3D tilt physics, swatches, hotspot zoom, interactive Bag drawer, and waitlist toasts.

## Getting Started
Open `index.html` in any modern web browser or serve locally:
```bash
python -m http.server 3000
```
Then navigate to `http://localhost:3000`.
